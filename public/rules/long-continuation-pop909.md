# POP909 长程生成一致性评分说明

先完整试听本组的「GT · 原曲参考」，再完整试听和评价下方各方法的 96 个 4/4 小节。GT 仅供参考，无需评分。各方法保留自身编码产生的 Prompt、起始相位与后续内容，不拼接或替换为 GT。

四个维度均采用与其他评测任务相同的 **1–5 分制**：

| 分数 | 定义 |
| --- | --- |
| **5 分** | **非常好**：表现优秀，几乎没有明显问题。 |
| **4 分** | **较好**：整体表现良好，存在少量问题，但基本不影响听感。 |
| **3 分** | **一般**：整体可以接受，但存在一些比较明显的问题。 |
| **2 分** | **较差**：存在较多明显问题，对整体听感造成较大影响。 |
| **1 分** | **很差**：存在严重问题，整体表现难以接受。 |

## 评分维度

**前后风格一致性**  
评价完整作品的前半段与后半段在整体曲风、情绪、织体和音乐语言上是否保持一致，是否出现明显突兀的风格变化。

**和声与节奏稳定性**  
评价调性、和声语言、节拍、速度感和律动是否稳定，是否出现缺少合理过渡的漂移、卡顿或崩坏。

**长程发展合理性**  
评价作品是否具有合理的段落变化、张弛与发展，同时避免长时间机械重复或无逻辑跳变。保持一致但完全没有发展，不应获得高分。

**后半段音乐质量**  
重点评价第 49–96 小节本身是否自然、完整，是否出现空轨、音符堆积、节奏失控、异常停顿或其他明显质量退化。
