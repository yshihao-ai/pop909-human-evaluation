# 伴奏生成评分说明

先试听本组的「GT · 原曲参考」，了解原曲旋律与伴奏，再评价下方生成结果。GT 仅供参考，无需评分。

请完整试听 16 个 4/4 小节的旋律与生成伴奏，再对每个样本评分。所有维度均采用 **1–5 分制**：

| 分数 | 定义 |
| --- | --- |
| **5 分** | **非常好**：表现优秀，几乎没有明显问题。 |
| **4 分** | **较好**：整体表现良好，存在少量问题，但基本不影响听感。 |
| **3 分** | **一般**：整体可以接受，但存在一些比较明显的问题。 |
| **2 分** | **较差**：存在较多明显问题，对整体听感造成较大影响。 |
| **1 分** | **很差**：存在严重问题，整体表现难以接受。 |

## 评分维度

**旋律与伴奏协调性**  
评价伴奏与给定旋律之间的协调程度，即伴奏是否能够自然、合理地配合并支持旋律。

**和声合理性**  
评价伴奏的和声合理性，包括是否符合给定的和弦进行（Chord Progression），以及是否存在明显的和声音高冲突或不合理的和弦使用。

**节奏一致性与伴奏型稳定性**  
重点评价伴奏的节奏型、节奏密度、速度感和律动是否保持一致、稳定，同时评价伴奏型和整体音乐组织的变化是否自然连贯。

**音乐正确性**  
评价伴奏中是否存在明显的音乐错误，例如不合理的不协和音、异常节奏、不自然的乐句（awkward phrasing），或其他明显影响听感的问题。

**整体质量**  
综合评价该伴奏的整体音乐质量，包括其自然度、流畅性、协调性，以及作为当前旋律伴奏的整体适合程度。
