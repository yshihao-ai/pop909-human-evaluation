# 音乐续写评分说明

先试听本组的「GT · 原曲参考」，再试听和评价下方各方法的结果。GT 仅供参考，无需评分。各方法保留自身编码产生的 Prompt 和起始相位；检查阶段若出现长度不足提示，请先核查数据，勿将本版检查分数用于正式统计。

请完整试听给定的 **4 小节 Prompt** 与后续 **12 小节 Continuation**（共 16 小节），再对每个样本评分。所有维度均采用 **1–5 分制**：

| 分数 | 定义 |
| --- | --- |
| **5 分** | **非常好**：表现优秀，几乎没有明显问题。 |
| **4 分** | **较好**：整体表现良好，存在少量问题，但基本不影响听感。 |
| **3 分** | **一般**：整体可以接受，但存在一些比较明显的问题。 |
| **2 分** | **较差**：存在较多明显问题，对整体听感造成较大影响。 |
| **1 分** | **很差**：存在严重问题，整体表现难以接受。 |

## 评分维度

**连贯性（Coherence）**  
评价续写部分与给定 Prompt 之间的衔接是否自然，以及前后在整体音乐风格上是否保持一致。重点关注旋律、节奏、织体和整体听感是否能够自然延续，是否存在明显突兀的风格变化。

**节奏一致性（Rhythmic Consistency）**  
重点评价续写部分自身的节奏是否连续、一致且稳定，包括节奏型、节奏密度、速度感和律动是否出现缺乏合理过渡的突然变化；同时留意明显卡顿、突然中断或不自然停顿。

**和声合理性（Harmony）**  
评价续写部分的音高与和声是否自然、协调。重点关注是否存在明显不和谐或不合理的音高、和弦冲突、异常音程，以及整体和声进行是否符合正常的音乐听感。

**整体质量（Overall Quality）**  
综合评价续写结果的整体音乐质量，包括续写是否自然、流畅、协调，并具有良好的音乐性和整体听感。
